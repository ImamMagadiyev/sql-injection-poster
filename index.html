The attack in one line

Type this in a login form, and a badly written website lets you in without a password:

bank.example/login
Usernameadmin
Password' OR '1'='1' --
Log inAccess granted: authentication bypassed

What the database actually runs:

SELECT * FROM users WHERE name = 'admin' AND pass = '' OR '1'='1' -- ' ← always true, the rest is a comment

This is SQL injection: the site mixes what you type into its database query, so your input runs as code.

You can't fix them all. You can fix the right ones.
